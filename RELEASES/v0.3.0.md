# GRIOT Semantic Engine v0.3.0

Phase-2 deterministic knowledge induction on top of the QUID semantic IR.

New capabilities:
- nested definitions: X is Y that has Z
- explicit property extraction
- numeric ranges with min/max/unit relations
- conditional structures with explicit implication scenes
- because/causal explanation extraction
- contradiction accounting during consolidation

This is structured knowledge acquisition, not neural model training.
The QUID invariant remains unchanged: one QUID = one Unicode code point.
