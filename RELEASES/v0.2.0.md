# GRIOT Semantic Engine v0.2.0

This release adds a semantic intermediate representation around the existing GRIOT engine.

Core invariant:
GRIOT is the engine. A QUID is one Unicode code point. Meaning is carried by typed relationships, scenes, evidence, numerical signatures and graph structure outside the QUID symbol.

Added:
- MeaningNode / MeaningEdge / MeaningRepresentation
- event scenes with has_agent and has_patient roles
- temporal constraints
- modality constraints
- numeric constraints
- explicit negation
- simple anaphora/reference resolution
- deterministic composed meaning vectors
- meaning-level similarity
- learning from compiled semantic edges into the existing knowledge graph

Compatibility:
The original v0.1.0 engine remains unchanged in griot_engine.py. v0.2.0 is additive through griot_semantic_ir.py.

Validation:
The local distribution has 14 core engine tests plus 5 semantic IR tests.
