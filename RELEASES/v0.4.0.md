# GRIOT Semantic Engine v0.4.0

Proof-oriented reasoning over the QUID semantic representation.

Adds:
- explicit supported/refuted/conflict/unknown states
- proof steps with relation, confidence, rule and provenance
- transitive proof support
- cause lookup for "why" style reasoning

This is a reasoning controller over structured knowledge; it does not replace the GRIOT engine or turn QUIDs into models.
