# SHEOL v0.2 — Runtime Foundation

SHEOL v0.2 turns the architectural specification into a working runtime foundation.

## Runtime path

Mission -> Spine -> Phase -> Worker -> Artifact -> Gate -> Commit -> Continuity Capsule -> Next Phase.

## Added

- persistent event/artifact interfaces
- capability-aware model routing
- WorkerContract
- OpenAI-compatible model provider
- LocalSandboxExecutor
- deterministic GateEngine
- ContinuityCapsuleCompiler
- integrated SheolRuntime
- isolated attempts and post-commit artifact persistence

## Execution plane

The GRIOT Mobile local sandbox is a first-class execution plane. SHEOL does not assume cloud execution.

## 5x claim

5x remains a falsifiable benchmark target. The architecture does not claim to have achieved it yet.
