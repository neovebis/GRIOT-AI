# Android Native Source of Truth

The canonical native Android code for GRIOT Mobile resides exclusively under:
`android/app/src/main/java/com/griot/app/`

This includes:

- `observer/GriotObserverService.java`
- `observer/GriotNotificationObserverService.java`
- `plugin/GriotPlugin.java`
- `notifications/GriotNotificationHelper.java`
- `notifications/GriotNotificationActionReceiver.java`
